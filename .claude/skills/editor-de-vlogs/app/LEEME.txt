EDITOR DE VLOGS - app local conectada con Claude Code
=====================================================
Que es: la interfaz para editar vlogs. Elegis en pestanas (Vlog, Material, Historia, Cortes,
Color, Audio, Musica, Textos, Exportar) y con "Editar con Claude" Claude Code edita en tu Mac.

Como abrirla (Mac):
  Doble clic en  "Editor de Vlogs.app"  (raiz del repo; arrastrala al Dock).  O pedirle a Claude Code
  "abri el editor de vlogs". Las dos corren abrir.sh: git pull, instala lo que falte, prende el
  servidor y abre http://localhost:8787 . Solo escucha en tu Mac. Log: ~/Library/Logs/EditorDeVlogs.log

Que necesita la Mac (una sola vez):
  1. Claude Code instalado y logueado con tu plan:  curl -fsSL https://claude.ai/install.sh | bash   y despues  claude  (login)
  2. ffmpeg:  brew install ffmpeg
  3. Python 3 + librerias:  pip3 install -r .claude/skills/editor-de-vlogs/requirements.txt

Como funciona por dentro:
  - Todo lo que elegis se guarda en  <carpeta del dia>/_edicion/vlog.json  (formato: references/vlog_json.md).
  - "Editar con Claude" corre:  claude -p "/editor-de-vlogs <ruta>/vlog.json <tu pedido>"
    con --output-format stream-json, permisos fijos (acceptEdits + ffmpeg/ffprobe/python3) y
    --resume para seguir la misma conversacion. El avance se ve en el panel de la derecha.
  - "Escanear carpeta" corre directo scripts/edicion/escanear.py (sin Claude).

Archivos:
  index.html          la app (todas las pestanas + Sala de Color integrada)
  sala_de_color.html  version suelta de la Sala de Color (la publicada en claude.ai, solo vista previa)
  ../servidor.py      servidor local (puente app <-> archivos <-> Claude Code)
